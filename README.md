# astra 测试

本地运行的 OpenAI 兼容上游检查工具。在页面顶部的配置卡填写服务地址、API Key、模型与推理强度，页面按固定顺序执行五项测试，并展示上游返回的原文与判定结果。API Key 使用 Windows 数据保护接口加密保存，明文不落盘、不写入日志、不回传页面。

## 产品定位

astra 测试回答一个具体问题：手上这个 OpenAI 兼容上游现在是否可用，能否按指令输出、能否算对一道明确的计数题、回答质量如何。

五项测试覆盖三类能力：

- 图形生成：按固定提示词生成带 2D 动画的 SVG；
- 推理与计数：一道条件明确、答案唯一的组合计数题；
- 基础问答：两个轻松提问与一个事实性问题，用于观察回答风格与知识时效。

判定只依据固定规则，不改写上游原文。测试结果反映的是本次请求在该模型上的表现，不代表模型的整体能力。

## 环境要求

- Windows 10 或 Windows 11。API Key 的加密存储依赖 Windows 数据保护接口（DPAPI）。
- Node.js 20 或更高版本。安装方式见 https://nodejs.org/，安装完成后确认命令行可执行 `node --version`。
- 不需要安装任何第三方依赖：仓库零运行时依赖，无构建步骤。

## 快速开始

### 一键启动

双击仓库根目录的 `start.bat`。脚本先检查 Node.js 是否可用，然后启动本地服务；服务就绪后自动用默认浏览器打开页面。关闭命令窗口即停止服务。

### 命令行启动

```
npm start
```

服务默认监听 http://127.0.0.1:8791，只接受本机访问。不需要自动打开浏览器时，使用：

```
node server/index.js --no-open
```

也可以在启动前把环境变量 `ASTRA_NO_OPEN` 设为 `1`。

## 配置说明

配置保存在页面最上方的「连接配置」卡中。点「保存配置」后立即持久化，下次启动继续生效。

### 服务地址

填写 OpenAI 兼容上游的地址。以下两种写法均可：

- 以 `/v1` 结尾：`https://api.example.com/v1`
- 完整的对话补全地址：`https://api.example.com/v1/chat/completions`

地址必须以 `http://` 或 `https://` 开头，否则保存时给出格式提示；末尾多余的 `/` 会被自动去掉。

对话补全请求与模型列表请求由服务按该地址自动拼接：以 `/v1` 结尾时分别访问 `<地址>/models` 与 `<地址>/chat/completions`；填写完整补全地址时，模型列表地址把结尾的 `/chat/completions` 换成 `/models`。

### API Key

- 尚未保存过 Key 时，必须先输入 Key 并保存。
- 已保存过 Key 时，输入框默认留空表示保持不变；输入新 Key 并保存会覆盖原 Key。
- 页面对已保存的 Key 只显示脱敏提示，形如「已加密保存，尾号 ab12；输入框留空表示保持不变。」；Key 长度不超过 8 位时尾号位置显示「----」，不展示真实尾号；完整 Key 不再回显。
- Key 使用 Windows 数据保护接口按当前 Windows 用户（CurrentUser 作用域）加密后写入磁盘，只有同一 Windows 账户能够解密。配置文件里没有 Key 明文。
- 页面顶部同时显示「本机加密存储可用」或「本机加密存储不可用」；不可用时无法保存配置。

### 模型

可手动输入任意上游模型名称，也可点「获取模型列表」，从上游返回的模型中选择（仍可自由输入）。

模型允许留空。留空时，执行测试前会先获取上游模型列表并使用第一个模型。模型列表获取失败时，卡片给出「未配置模型，且无法获取上游模型列表：…」的说明；列表为空时提示手动填写模型。两种情况下该项测试均记为输出异常。为避免上游默认顺序变化影响结果，建议显式填写模型。

### 推理强度

五档互斥单选，未配置时默认 `high`：

| 档位 | 说明 |
| --- | --- |
| 无（不思考） | 不要求模型输出思考内容 |
| medium | 较低强度 |
| high | 默认档位 |
| xhigh | 较高强度 |
| max | 最高强度 |

上游不支持该参数时自动降级：例如 `high` 先按 `high` 发送，若上游以 400 或 422 拒绝、且错误说明与推理强度有关，则改为不发送该参数重试。`无（不思考）` 的顺序为 `none` → `minimal` → 不发送该参数。降级成功后测试继续执行。结果卡在推理强度后标注「（已降级·实际发送 <档位>）」；若最终未发送该参数，则标注「（已降级·未发送该参数）」，降级原因可在悬停提示中查看；未降级时只显示「推理强度 <档位>」。所有档位都被拒绝时，该项记为输出异常。

### 保存与清空

- 「保存配置」写入当前填写的内容；保存后测试按钮才可用。
- 「清空配置」经二次确认后删除配置文件与内存中的配置，恢复为未配置状态；清空后需重新保存配置才能测试。
- 清空会同时删除 API Key。仅在 Key 输入框中留空并保存，不会清除已保存的 Key。

## 测试项与判定

五个测试项按固定顺序串行执行，同一时刻只执行一项。每张结果卡展示提示词原文、上游返回正文、元信息（模型、推理强度、耗时、用量）与可折叠的原始输出，并提供单卡「重新测试」。

| 顺序 | 测试项 | 提示词 | 判定规则 |
| --- | --- | --- | --- |
| 1 | 鹈鹕测试 | 用SVG画一只鹈鹕骑自行车的2d动画，只返回SVG code | 成功提取并渲染 SVG：已返回；提取或解析失败、请求失败、超时：输出异常 |
| 2 | 糖果测试 | 见下方提示词原文 | 答案等于 21：通过；答案为其他数字或没有数字：未通过 |
| 3 | 问答 A · ciallo | ciallo | 非空正文：已返回；空正文或请求失败：输出异常 |
| 4 | 问答 B · 叮咚鸡 | 叮咚鸡 | 非空正文：已返回；空正文或请求失败：输出异常 |
| 5 | 问答 C · 现任日本首相 | 仅凭你的记忆，直接回答现在的日本首相是谁 | 非空正文：已返回；空正文或请求失败：输出异常 |

状态与卡片外框高光：

| 状态 | 外框高光 | 触发条件 |
| --- | --- | --- |
| 待测试 | 无 | 初始状态，或清除结果之后 |
| 测试中 | 无 | 请求进行中 |
| 通过 | 绿色 | 仅糖果测试：答案等于 21 |
| 未通过 | 红色 | 仅糖果测试：答案不等于 21（含没有数字） |
| 已返回 | 无 | 鹈鹕测试的 SVG 渲染成功，或问答测试收到非空正文 |
| 输出异常 | 黄色 | 鹈鹕测试未提取到可解析的 SVG、正文为空、请求失败或超时 |

鹈鹕卡在答案区直接渲染 SVG 动画（自适应卡片宽度）；糖果卡并排展示提取到的答案与期望值 21；问答三项只展示正文，不做额外评判。问答 C 依赖模型的记忆，答案可能随政局变化，仅供观察。

运行控制：

- 「开始测试」按固定顺序执行全部五项，进度显示「已完成 n / 5」。
- 「停止」中止当前请求，当前项记为输出异常，后续项不再执行。
- 「清除结果」把所有卡恢复到待测试；运行中会先停止当前请求。
- 单卡「重新测试」只重跑该项。配置存在未保存修改、尚未保存服务地址或尚未保存 Key 时，不能开始测试，配置卡会给出原因。

### 糖果测试提示词原文

提示词逐字发送，数量表以制表符分隔：

```text
袋子里有三种口味的糖——苹果、桃子、西瓜。每种口味又有两种形状，圆形和五角星。摸糖的时候，形状靠手感就能分辨。

不同口味和形状的数量如下。

苹果	桃子	西瓜
圆形	7	9	8
五角星	7	6	4

问题是：最少取多少颗，能保证手里同时有一组「圆形苹果 + 五角星桃子」或者「五角星苹果 + 圆形桃子」？

直接回答数字，禁止输出任何其他内容
```

## 安全与数据

- 服务只监听 127.0.0.1，不对外网开放；页面与接口同源，不使用外部资源。
- 配置文件位置：`%APPDATA%\astra-test\config.json`。`APPDATA` 不存在时回落到用户主目录下的 `.astra-test/config.json`。
- 配置文件中保存服务地址、模型、推理强度、加密后的 Key、末四位提示与更新时间；不保存 Key 明文。
- 「清空配置」删除该配置文件并清空内存状态；也可手动删除该文件后重新启动服务。
- 变更类请求会校验请求来源与内容类型，跨站请求被拒绝；页面响应带有内容安全策略，限制外部资源加载。

## 常见问题

### 端口被占用

默认端口 8791。被占用时会在其后 10 个端口内自动顺延，实际地址以控制台输出为准；全部被占用时给出可读错误并以非零状态退出。需要固定端口时，启动前设置环境变量 `ASTRA_PORT`，例如 PowerShell：

```powershell
$env:ASTRA_PORT=9000
npm start
```

`ASTRA_PORT=0` 表示由系统分配空闲端口。

### 上游返回 401 或 403

表示 Key 或权限问题：Key 无效、已过期、没有访问所选模型的权限，或服务地址指向了错误的上游。请核对 Key、服务地址与账户权限。在页面操作时若提示来源不受信任，请确认页面是通过 `http://127.0.0.1:<端口>` 打开的。

### 上游不支持推理强度参数

无需手动处理。程序按档位自动降级重试，成功后继续执行：降级时卡片标注实际发送的档位或「未发送该参数」，降级原因可悬停查看；若所有档位都被拒绝，该项记为输出异常，卡片显示请求失败的状态码与可读说明。

### 非 Windows 系统不可用

API Key 的加密存储依赖 Windows 数据保护接口。在非 Windows 系统上服务可以启动、页面可以打开，但无法保存 Key，因而不能执行测试。请使用 Windows 10 或 Windows 11。

### 模型留空时如何选择

留空时自动取上游模型列表的第一个模型；模型列表获取失败时给出「未配置模型，且无法获取上游模型列表：…」的说明，列表为空时提示手动填写模型，两种情况下该项均记为输出异常。建议填写明确的模型名称。

### 页面没有自动打开

手动访问控制台输出的地址，默认 http://127.0.0.1:8791。端口顺延时以实际输出为准。

### 请求超时

单次上游请求默认超时 10 分钟（600000 毫秒）。需要调整时，启动前设置环境变量 `ASTRA_TIMEOUT_MS`（单位毫秒）。

## 本地联调

仓库内置假上游 `tools/mock-upstream.js`，用于在不消耗真实额度的情况下验证页面、接口与判定逻辑：

```
node tools/mock-upstream.js
```

启动后输出 `ASTRA_MOCK_READY http://127.0.0.1:8799`。在页面中把服务地址填为 `http://127.0.0.1:8799/v1`，API Key 填任意非空值即可（假上游只检查请求是否携带授权头）。也可使用 `npm run mock` 启动默认模式。

参数：

| 参数 | 说明 |
| --- | --- |
| `--port N` | 监听端口，默认 8799；`--port 0` 表示由系统分配 |
| `--mode good` | 默认模式：五项均正常返回，糖果答案为 21，鹈鹕返回可渲染的 SVG |
| `--mode wrong-candy` | 糖果答案返回 23，用于验证红色「未通过」 |
| `--mode bad-svg` | 鹈鹕返回非 SVG 文本，用于验证黄色「输出异常」 |
| `--mode empty` | 返回空正文，用于验证空响应的「输出异常」 |
| `--reject-effort` | 拒绝推理强度参数（返回 400），用于验证自动降级 |

## 测试命令

```
npm test
```

等价于 `node --test "tests/**/*.test.mjs"`，包含三组用例：

- 后端用例：配置存取与清空、加密存储、服务地址归一化、推理强度降级、上游事件流代理、请求护栏与静态托管。
- 前端用例：提示词逐字一致、SVG 提取、糖果答案判定与状态高光映射。
- 端到端用例：真实启动假上游与后端进程，使用系统分配端口与临时配置目录，不读写本机用户配置；覆盖保存配置、五项测试、落盘检查、重启后配置仍在、清空配置与再次重启。

只运行端到端用例：

```
node --test tests/e2e.test.mjs
```

端到端用例在非 Windows 系统上因加密存储不可用而跳过。
